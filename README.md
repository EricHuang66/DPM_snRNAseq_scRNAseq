# DPM_snRNAseq_scRNAseq
The code accompanying the paper, *Single-cell and single-nucleus transcriptomics reveal impaired laminin-dystroglycan/integrin signaling in adolescent idiopathic scoliosis patients*, contains read counts per sample, sample merging, QC, dimensionality reduction, and cluster definition. In addition, the marker files are provided in the *_markerlist.txt format.
